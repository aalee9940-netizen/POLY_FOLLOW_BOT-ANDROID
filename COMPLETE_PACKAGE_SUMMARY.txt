STEP 1: Install Docker
  - Windows: https://www.docker.com/products/docker-desktop
  - Mac: https://www.docker.com/products/docker-desktop
  - Linux: sudo apt-get install docker.io

STEP 2: Download all files from /files/ directory

STEP 3: Create a folder and extract/copy all files there

STEP 4: Open terminal/command prompt in that folder

STEP 5: Run this command:
  docker-compose up

STEP 6: Wait for build (15-20 minutes first time)

STEP 7: Your APK will be at:
  ./polymarket-bot-apk/build/outputs/apk/release/app-release.apk

STEP 8: Install on phone:
  adb install ./polymarket-bot-apk/build/outputs/apk/release/app-release.apk
  
  OR transfer file and tap to install

Time: 15-20 minutes
Difficulty: ⭐ Very Easy
Requirements: Docker only (no Java, no Android Studio needed!)


METHOD 3: BUILD WITH ANDROID STUDIO (HARDEST - 1 HOUR)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Install Android Studio
  https://developer.android.com/studio

STEP 2: Download all files to your computer

STEP 3: In Android Studio: File → Open → Select project folder

STEP 4: Let Android Studio sync Gradle (wait 10 minutes)

STEP 5: Click Build → Build APK

STEP 6: Wait for build (30 minutes)

STEP 7: APK will be at:
  app/build/outputs/apk/debug/app-debug.apk

STEP 8: Connect phone and install:
  adb install app/build/outputs/apk/debug/app-debug.apk

Time: 1 hour
Difficulty: ⭐⭐⭐ Hard
Requirements: Android Studio, Java 11+, Android SDK, Gradle

📱 AFTER YOU GET THE APK - INSTALLATION
================================================================================

STEP 1: Enable Installation from Unknown Sources
  On your Android phone:
  Settings → Apps → Special app access → Unknown sources
  Toggle ON

STEP 2: Transfer APK to Phone
  Option A (USB): Connect phone, copy file via file manager
  Option B (Email): Email APK to yourself, download on phone
  Option C (Cloud): Upload to Google Drive, Dropbox, etc.
  Option D (Bluetooth): Send via Bluetooth

STEP 3: Install
  1. Open file manager on phone
  2. Find the APK file
  3. Tap to install
  4. Click "Install"

STEP 4: Configure Bot
  1. Open the app
  2. Enter your Polymarket credentials:
     - Private key
     - Funder address
     - Trading parameters
  3. Click "Start Trading"

STEP 5: Monitor
  App runs on your phone and starts monitoring/trading!

🆘 TROUBLESHOOTING
================================================================================

PROBLEM: Docker command not found
SOLUTION: Install Docker from https://www.docker.com/products/docker-desktop

PROBLEM: Build fails / out of disk space
SOLUTION: Free up 5GB disk space and try again

PROBLEM: APK won't install
SOLUTION: Enable "Unknown sources" in phone settings

PROBLEM: "docker-compose: command not found"
SOLUTION: Check Docker installed correctly, restart terminal

PROBLEM: App crashes on startup
SOLUTION: Check Android version is 7.0 or higher

PROBLEM: Where do I find the built APK?
SOLUTION: Look in ./polymarket-bot-apk/build/outputs/apk/release/
