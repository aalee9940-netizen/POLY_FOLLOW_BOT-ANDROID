🎯 CHOOSE YOUR BUILD METHOD
================================================================================

METHOD 1: DOCKER BUILD (EASIEST) ⭐
─────────────────────────────────────────────────────────────────────────────
Best for: Everyone, especially Windows users

Prerequisites:
  • Docker Desktop (https://www.docker.com/products/docker-desktop)

Steps:
  1. Install Docker Desktop
  2. Edit config.json with your private_key, funder, wallets
  3. Run: docker-compose up
  4. Wait 45-90 minutes
  5. APK ready at: output/bin/polymarket_bot-*.apk

No Java, No Android SDK needed!


METHOD 2: SHELL SCRIPT BUILD
─────────────────────────────────────────────────────────────────────────────
Best for: Linux and macOS users

Prerequisites:
  • Python 3.9+
  • Java JDK 11+
  • ~50GB disk space

Steps:
  1. chmod +x build_apk.sh
  2. ./build_apk.sh
  3. Follow interactive prompts
  4. Wait 30-60 minutes
  5. APK ready at: bin/polymarket_bot-*.apk


METHOD 3: MANUAL BUILD
─────────────────────────────────────────────────────────────────────────────
Best for: Advanced users with full control

See: ANDROID_BUILD_GUIDE.md for detailed instructions

⚠️ IMPORTANT SETUP
================================================================================

BEFORE BUILDING:

1. Copy your bot files:
   • Copy all .py files from your original bot to this directory
   • Copy your config.json file here

2. Edit config.json:
   • Set "wallets": ["your_wallet_address"]
   • Set "private_key": "your_private_key"
   • Set "funder": "funder_address"
   • Review other settings

3. Choose build method and follow instructions above

📱 INSTALL ON YOUR ANDROID DEVICE
================================================================================

AFTER BUILD COMPLETES:

Via ADB (Fastest):
  $ adb install -r bin/polymarket_bot-1.0.0-debug.apk

Via File Transfer:
  1. Copy APK to your Android device
  2. Open Files app
  3. Tap APK file
  4. Tap Install

VIA WEB (Share with yourself):
  1. Upload APK to cloud storage (Google Drive, Dropbox, etc)
  2. Share link to yourself
  3. Download on Android device
  4. Open and install

🔐 SECURITY SETUP
================================================================================

BEFORE RUNNING THE BOT:

1. Enable USB Debugging (for installation):
   Settings → About Phone → Tap Build Number 7 times
   Settings → Developer Options → USB Debugging: ON

2. Device Security (for protection):
   ✓ Enable device encryption
   ✓ Set strong lock screen PIN (6+ digits)
   ✓ Use dedicated phone (not personal device)
   ✓ Enable Find My Mobile/Google Find My Device

3. App Permissions:
   • The app needs INTERNET permission
   • Grant when prompted during first run

4. Financial Safety:
   • Keep only trading amounts on the account
   • Store main assets in cold wallet
   • Start with small amounts
   • Monitor daily

🚨 COMMON ISSUES & SOLUTIONS
================================================================================

"Docker: command not found"
→ Install Docker Desktop: https://www.docker.com/products/docker-desktop

"Python: command not found"
→ Install Python 3.9+: https://www.python.org/downloads/

"Java: command not found"
→ Install Java: apt-get install openjdk-11-jdk (Linux)
                brew install openjdk@11 (macOS)

"APK won't install"
→ uninstall old: adb uninstall org.trading.polymarket
  install fresh: adb install -r bin/polymarket_bot-1.0.0-debug.apk

"Build fails with SDK error"
→ Clear cache: buildozer android clean
  Retry build

"App crashes on startup"
→ Check device storage: adb shell df -h
  Check config.json is valid JSON
  Check logs: adb logcat | grep polymarket
