If you want to build the APK yourself (no coding required):

Step 1: Install Docker
  - Windows: https://www.docker.com/products/docker-desktop
  - Mac: https://www.docker.com/products/docker-desktop  
  - Linux: sudo apt-get install docker.io

Step 2: Extract this ZIP file

Step 3: Open terminal in the extracted folder

Step 4: Run this command:
  docker-compose up

Step 5: Wait for build to complete (15-20 minutes first time)

Step 6: APK will be at:
  build/outputs/apk/release/app-release.apk

Step 7: Install on phone:
  adb install build/outputs/apk/release/app-release.apk
  
  OR transfer file and tap to install

Time: 15-20 minutes (first build takes longer)
Difficulty: ⭐ (Very Easy)

Installation Steps:

1. On your Android phone:
   Settings → Apps → Special app access → Unknown sources
   (Enable to allow installing non-Play Store apps)

2. Transfer the APK file to your phone via:
   - USB cable and file manager
   - Email
   - Cloud storage (Google Drive, Dropbox, etc.)
   - Bluetooth

3. Open file manager and tap the APK
   
4. Click "Install"

5. Once installed, open the app

6. Configure:
   - Polymarket private key
   - Funder address  
   - Trading parameters
   - Click "Start Trading"

7. App runs on your phone and starts trading!

TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

"Docker command not found"
  → Install Docker from: https://www.docker.com/products/docker-desktop

"Build fails"
  → Check you have 4GB free disk space
  → Ensure stable internet connection
  → Try again: docker-compose up

"APK won't install on phone"
  → Enable "Unknown sources" in phone settings
  → Uninstall old version first
  → Try: adb install -r app-release.apk

"Where's my APK?"
  → It's in: ./build/outputs/apk/release/app-release.apk
